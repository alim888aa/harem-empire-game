# Research

On the Friday schedule, start the `researcher` skill as a subagent on an
open run. Start it with a question when you're stuck, such as the same
bug reopening or the same ask coming back.

The manager brings you its `type:idea` items. For each:

- **Accept**: plan it as **Asks into work** says, and close the idea
  linking the plan.
- **Turn down**: close it as not planned with the reason.
- **Spike first**: start the researcher on the spike and leave the
  idea's labels alone. Decide when it reports back.

Send the manager `decided #<n>` once the idea is settled.
